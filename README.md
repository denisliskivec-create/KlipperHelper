# KlipperHelper
Round IPS mini-monitor &amp; NTP desk clock for Klipper / Moonraker 3D printers (ESP8266 + GC9A01 240x240). Features real-time telemetry, idle clock mode, and bilingual Web UI. 

Круглый IPS мини-монитор и NTP-часы для 3D-принтеров Klipper / Moonraker (ESP8266 + GC9A01). Телеметрия печати, режим часов при простое и веб-панель настроек.
